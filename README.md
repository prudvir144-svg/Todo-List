
# Project : To-Do List CLI App

## Description
A command-line task manager built with Python.
It allows users to add tasks, list tasks, and mark tasks
as completed. Tasks are stored in a JSON file.

## Features
- Add new tasks
- Display all tasks
- Mark tasks as completed
- Store tasks in JSON
- Load saved tasks when the program starts
- Handle missing task files and invalid commands

## Technologies Used
- Python
- JSON
- Command-line interface

## How to Run
Add a task:
`python todo.py add "Buy milk"`

List tasks:
`python todo.py list`

Complete a task:
`python todo.py done 1`

## Files
- `todo.py` - Main application
- `tasks.json` - Saved tasks (created automatically)
